# مناسبات الكويت - Kuwait Occasions 🇰🇼

الموقع التعريفي واللاندنج بيج الرسمي لتطبيق **مناسبات الكويت** (منصة تنظيم وتوثيق ومتابعة مناسبات القبائل والعوائل في دولة الكويت).

---

## 🌟 مميزات المشروع
- **تصميم عصري متجاوب بالكامل**: يعمل بكفاءة تامة على جميع الهواتف الذكية، الأجهزة اللوحية، وشاشات الحواسيب المكتبية.
- **هوية بصرية فاخرة**: تعتمد على اللون الكحلي الملكي (`#1445A0`) واللون الذهبي الفاخر (`#F4B942`).
- **أنيميشن سلس (Scroll Reveal)**: تأثيرات حركة وظهور متتابعة للأقسام والكروت تعتمد على `IntersectionObserver`.
- **ثنائي اللغة (i18n)**: دعم فوري للتبديل بين اللغتين العربية والإنجليزية.
- **دعم الوضع الليلي والنهاري**: Dark / Light theme.
- **أقسام متكاملة**:
  - الهيرو التفاعلي والتعريف بالمنصة.
  - قسم المميزات: الرزنامة الذكية، بطاقات الدعوة ولوكيشن القاعات، دليل القبائل، دليل المأذونين المعتمدين لمحافظات الكويت الست، دليل التجهيزات والضيافة، والرعايات التجارية.
  - قسم خطوات استخدام التطبيق.
  - بانر تحميل التطبيق (App Store & Google Play).
  - صفحة الشروط والأحكام (`terms.html`).
  - صفحة سياسة الخصوصية (`privacy.html`).

## 🚀 المعاينة والتشغيل
المشروع مبني بتقنيات الويب النقية (HTML5, CSS3, Vanilla JavaScript) ولا يتطلب أي حزم تثبيت أو خوادم خلفية.
يمكنك فتحه مباشرة في أي متصفح ويب عبر تشغيل ملف `index.html`.
